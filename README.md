# I TECH DDIGITAL AI

I TECH DDIGITAL AI is a webinar registration and digital business landing page.

## Technology

- Node.js
- Express.js
- MongoDB
- Mongoose
- Nodemailer
- HTML
- CSS
- JavaScript

## Features

- Webinar registration
- MongoDB lead storage
- Email confirmation
- Google Meet integration
- WhatsApp channel integration
- FAQ accordion
- Webinar reminders
- Duplicate registration protection
